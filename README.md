
## Git версионирование
- Ветки по темам: feature/01-basics,
  feature/02-cypher-crud и т.д.
- Conventional Commits: docs:, fix:, upd:, init:, style:, feat:, ref:
- Проверка: все запросы тестируются
  в Neo4j Browser перед мержем в main
- Обновление: по мере изучения новых тем

Формат: <тип>: <описание>

Типы:
├── feat  — создание нового файла
├── style — форматирование файла
├── init  — первоначальное создание репозитория
├── docs  — добавление нового раздела справочника
├── fix   — исправление ошибок в существующем разделе
├── upd   — обновление устаревшей информации
└── ref   — реструктуризация без изменения содержимого

Примеры:
✅ init: создан репозиторий справочника Neo4j
✅ docs: добавлен раздел CRUD операций
✅ fix:  исправлен пример DETACH DELETE
✅ upd:  обновлён синтаксис под Neo4j 5.x
✅ ref:  переименованы файлы согласно конвенции

❌ "изменения"
❌ "правки"
❌ "обновил файл"
